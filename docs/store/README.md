# Store artwork

- `icon.png`: 512 × 512, original rising-bars mark on an opaque navy background.
- `feature-graphic.png`: 1024 × 500, matching brand colors and original copy.
- SVG files retain editable geometry and text. `tools/render-store-assets.ps1` reproduces the PNG
  versions on Windows with Segoe UI; SVG viewers may use a different fallback font.

These are prepared assets, not an uploaded store listing. They do not contain real health data.
Screenshots for the listing still need to be chosen from the final release UI.
